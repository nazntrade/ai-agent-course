# AI Agent Course

Учебные задания курса по AI-агентам. Этот репозиторий хранится отдельно от проекта AI-Server.

## Структура

- `week-01/llm-api-project` — развивающийся проект первой недели: запросы к LLM через DeepSeek API и локальную модель (Дни 1–5).
- `week-02/first-agent` — развивающийся проект второй недели «Первый агент»: агент как отдельная сущность с инкапсулированной историей диалога, DeepSeek API, Streamlit-интерфейсом, хранением контекста в SQLite и управлением контекстом (сжатие старой части истории в накопительную сводку).

## Агентская разработка

Задачи в репозитории выполняет команда ИИ-агентов. Пользователь ставит задачу обычным языком и не выбирает агента сам.

- **Coordinator** анализирует задачу, маршрутизирует её между агентами и принимает результат.
- **Architect** проектирует сложные изменения, но ничего не редактирует.
- **Developer** реализует изменения и запускает проверки.

Обязательные правила работы находятся в `AGENTS.md`, конфигурации ролей — в `.opencode/agents/`.
