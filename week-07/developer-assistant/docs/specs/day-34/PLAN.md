## Доказательства, актуальность и публикация

Каждому D34-XX соответствует frozen JSON artifact `local-data/d34-evidence/D34-XX-*.json`, count 1..32; схема и glob не переименовываются. Записывать новые версии с provenance, не перетирать failed evidence. У record: criterion, дата/метод, source/spec hashes, run/provider/baseline/revision, inputs/limits, полное безопасное actual output либо проверяемые ссылки/хеши полного output, observed outcomes и limitations. Tool results не сводятся к флагу success. Secret bytes/endpoints/private roots не попадают в публичные артефакты; hashes сохраняются для traceability.

Независимый Tester читает фактические совпавшие artifacts, возвращает acceptance-evidence-v2 всех исходных 21 ID с refs на каждый matched file, отдельно технический TEST_STATUS и substantive result. PASS каждого ID требует соответствующих LIVE/BROWSER/ARTIFACT/MANUAL/OFFLINE/GIT checks, не одного наличия JSON. Спецификационные критерии идут отдельным контрактом; в продуктовую матрицу их не подменяют.

Корневой publisher после privacy audit публикует точные необходимые code/tests/docs/results. Правила/settings/env/local runtime evidence не публикуются. Перед публикацией — исходный snapshot, diff и точный staged scope; после — actual target remote HEAD и whole Course tracked/untracked status, без скрытия нужных файлов через ignore. Если остаётся обязательный FAIL/PARTIAL/NOT_ASSESSED, общий результат не ACCEPTED. Архитектор в этой стадии не выполняет commit/push и не принимает собственный дизайн независимо.
