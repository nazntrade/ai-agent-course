## Решения

- Стек: Python + FastAPI + Pydantic + SQLite, статический HTML/JS без сборки и CDN (SPEC §13, §16).
- Адаптеры между хранилищем и потребителем: `IndexStore` и `KnowledgeService` (SPEC §5.3).
- Manifest индекса и полный набор metadata чанка (SPEC §6.4, §6.3).
- Дедупликация через `fingerprint` и `INSERT OR IGNORE` (SPEC §9.5).
- Атомарная активация индекса в `BEGIN IMMEDIATE`, один build на процесс (SPEC §9.1–§9.2).
- Точный cosine — только для маленького корпуса; контракт `IndexStore` готов к ANN (SPEC §9.3).
